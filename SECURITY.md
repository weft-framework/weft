# Security Policy

## Supported versions

Weft is pre-1.0. Only the latest release and the `main` branch receive security
fixes.

## Reporting a vulnerability

Please report privately, not in a public issue, pull request or discussion. Use
GitHub's private vulnerability reporting: open the **Security** tab on the
repository, then **Report a vulnerability**.

A useful report names the version or commit, includes the smallest `.wx` file,
route or request that shows the problem, and says what an attacker gains (reads
another user's rows, runs script in a page, acts as another session, and so
on).

You will get an acknowledgement within a few days, and credit in the advisory
unless you would rather not be named. Please give us time to ship a fix before
disclosing publicly.
